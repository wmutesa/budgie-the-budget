# Taskie wiki

Taskie is a planner for students that you talk to: say everything on your mind and Taskie turns it into a planned schedule, with reminders on your laptop and phone. There is nothing to install: it runs in any up-to-date browser (and from the Home Screen on a phone), and each person's data syncs to their own invite-only account.

**The code is public; your data is not.** The repository holds only source code. Tasks, routines, goals and settings live in each person's private account. Recordings are heard once (Deepgram Nova-3, then Gemini) and never kept. The address of a running Taskie is shared only with the people invited to it.

- **Code:** https://github.com/wmutesa/taskie-the-task
