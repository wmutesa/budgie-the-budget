# Budgie wiki

Budgie is a personal web app for money: spending, subscriptions, budgets, savings goals, accounts and the markets, with an AI helper that runs on your own device. There is nothing to install: it runs in any up-to-date browser, and each person's data syncs to their own invite-only account.

**The code is public; your data is not.** The repository holds only source code. Entries, budgets, accounts, goals and settings live in each person's private account, and the AI runs on the device with no cloud service and no API keys. The address of a running Budgie is shared only with the people invited to it.

- **Code:** https://github.com/wmutesa/budgie-the-budget
